# Rules

## Documentation

- Update documentation only when a change affects the information it contains.

## Git

- Do not stage, commit, or push code unless explicitly required by the user.
- Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages (e.g. `docs:`, `build:`, `chore:`, `feat:`, `fix:`).

## Go

- After modifying any Go files, run `gofumpt -w` on the changed files to ensure they are properly formatted.

## Platform

- This software is only meant for Linux systems.
